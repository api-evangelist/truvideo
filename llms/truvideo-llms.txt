# TruVideo

> TruVideo is a video-intelligence and omnichannel communication platform for
> service businesses — built for the automotive service market (dealers, service
> advisors, technicians) and expanding into aviation, insurance and commercial
> trucking. It captures technician videos, runs AI features (noise cancellation,
> sentiment analysis, multilingual virtual assistant) and drives customer
> messaging conversations tied to repair orders. Its public developer surface is
> an SDK-first family of on-device capture modules plus a REST Platform API.

## API

- [OpenAPI (reconstructed)](openapi/truvideo-openapi.yml): TruVideo Platform REST API v2 — 29 operations across authentication, users, dealers, repair orders, videos, messaging conversations, customers, files, chat, reports and support.
- Production host: https://app.truvideo.com
- Sandbox host: https://dev.truvideo.com (requires a provisioned TruVideo Sandbox account)
- Authentication: JWT bearer. POST /api/v2/authentication/login returns a token used in the Authorization header.

## SDKs

TruVideo ships modular capture SDKs (core / camera / video / media / image) per platform, distributed via GitHub:

- iOS (Swift, SPM + CocoaPods): https://github.com/Truvideo (truvideo-sdk-ios-*)
- Android (Kotlin, Gradle/Maven): truvideo-sdk-*-android-net
- .NET / MAUI (C#, NuGet): truvideo-sdk-*-net
- React Native (TypeScript): TruVideoReact*Sdk
- Capacitor (TypeScript): TruVideoCapacitor*Sdk
- iOS SDK docs: https://github.com/Truvideo/truvideo-sdk-ios-documentation
